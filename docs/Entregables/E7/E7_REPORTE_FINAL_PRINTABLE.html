Cache Layer: Redis 8-alpine

  • Feed caching → reduce DB load 30%+
  • TTL configurado → garantiza datos frescos (máx 1 hora old)
  • 0 evictions durante stress test → sufficient memory

SECCIÓN 6: Recomendaciones Post-Certificación

6.1 Inmediatas (Pre-Deployment)

  1. Configuración de Grafana Alerting (P1): Establecer thresholds para alertas automáticas
    • P(95) latency > 800ms → WARN
    • P(95) latency > 1500ms → CRITICAL
    • Error rate > 3% → WARN
    • CPU > 60% → WARN (headroom)
  2. Logging de Queries Lentas (P2): PostgreSQL `log_min_duration_statement = 500`
  3. Rate Limiting Auth (P2): Middleware throttle en `/api/auth/*` (200 req/min por IP)

6.2 Escalabilidad Futura

  • Horizontal Scaling: Agregar más Octane workers (actualmente 4, soporta 8+)
  • Database Replication: Read replicas para queries analíticas (sin impactar transaccionales)
  • CDN + Caching: Cache HTTP en CDN para mapas (GeoJSON static)
  • Cursor-based Pagination (P3): Cuando dataset > 100K registros

6.3 Monitoreo en Producción (Primeras 2 semanas)

  • Revisar logs diarios de queries lentas (esperado: < 5% de queries)
  • Monitorear Redis memory (esperado: < 500MB con TTL activo)
  • Validar que indexación PostGIS es eficiente en queries geoespaciales reales
  • Confirmar que certificados SSL/TLS funcionan en producción
