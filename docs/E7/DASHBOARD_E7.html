⚠️ Cuellos de Botella Identificados

B01

Eloquent N+1 Query Problem

Múltiples queries por relación en listados de incidencias (category, location, user, organization).

🔧 Fix: Verificar eager loading con with(['category', 'location', 'user', 'organization'])
B02

Índice PostGIS GiST puede no existir

Queries geoespaciales ST_Within sin índice GiST causan full table scan.

🔧 Fix: CREATE INDEX incidents_geom_idx ON incidents USING GIST (geom);
B03

Single Octane Worker

Un solo worker puede saturar CPU bajo carga. Recomendado: 4+ workers.

🔧 Fix: php artisan octane:start --workers=4
